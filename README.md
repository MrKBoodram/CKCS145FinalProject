# CKCS145FinalProject
Final Project for Full Stack Developer Certificate Course @ Chang School

Test Commit:

This project aims to create a web-application to document trades. 
    MVP Requirements: 
        1. Data Intake via API or CSV to Database
        2. Enable writing to DB via Flask middleware
        3. Process Data utilizing Python + additional libraries
        4. Create Visualizations of Data 
        5. Display information on single/multi-page front-end, stylized using libraries and tooling such as React (JS) & Bootstrap (CSS)
        6. Code with the bare minimum in terms of WCAG guidelines in mind
