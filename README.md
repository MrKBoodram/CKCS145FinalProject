# CKCS145FinalProject
Final Project for Full Stack Developer Certificate Course @ Chang School

This project aims to create a web-application to document trades. 
    MVP Requirements: 
        1. Data Intake via API or CSV to Database - (completed)
        2. Enable writing to DB via Flask middleware - (completed)
        3. Process Data utilizing Python + additional libraries - (completed)
        4. Create Visualizations of Data - (completed)
        5. Display information on single/multi-page front-end, stylized using libraries and tooling such as React (JS) & Bootstrap (CSS) - (completed)
        6. Code with the bare minimum in terms of WCAG guidelines in mind - (in Progress)
